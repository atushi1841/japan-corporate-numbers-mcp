# japan-corporate-numbers-mcp

MCP server for Japan's National Tax Agency (国税庁) corporate number registry. Query company registration data by name or corporate number.

## Endpoint

```
https://fruitful-quintessence--japan-corporate-numbers.apify.actor/mcp
```

Requires Apify API token (Bearer auth).

## Data Source

Official NTA 法人番号 (Kojin Bangō) registry — public government data.

## Pricing

$0.002 per result (Apify pay-per-event).
